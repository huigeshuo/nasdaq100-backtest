# 纳斯达克 100 ETF 定投回测工具

> 底仓 + 每月定投，用 QQQ 二十余年真实行情跑一遍：同样的钱，坚持下来会变成多少。

**在线使用**：<https://huigeshuo.github.io/toolbox-s/>

不用安装任何东西，手机、电脑打开即用。全部计算在浏览器本地完成，行情数据已内嵌在页面里，不联网、不请求任何接口。

## 回测什么

| 参数 | 说明 |
|---|---|
| 底仓金额 | 起始日一次性买入的金额（默认 10 万） |
| 每月定投金额 | 此后每月固定追加的金额（默认 1000） |
| 起始年份 / 结束年份 | 回测区间，数据覆盖 2001–2026 |

## 计算规则

- 价格为 **QQQ 前复权日线**，买入按当日收盘价折算成**整数股**
- 当月资金不足 1 股时，**余额不清零**，累积到下个月继续买
- 输出总投入、期末市值、年化收益率、最大回撤，并绘制资产曲线

这套规则刻意贴近真实操作：散户买 ETF 只能买整数股，零钱不会凭空生息，因此结果比"按份额无限可分"的理想模型更保守，也更接近实际账户。

## 三种用法

| 方式 | 适用 | 说明 |
|---|---|---|
| 在线版 | 手机/电脑随手查 | `docs/index.html`，单文件自包含 |
| 离线单文件 | 无网络环境 | 把 `docs/index.html` 存到本地，双击打开 |
| Streamlit 版 | 想换标的、改数据 | `app.py`，可重新抓取行情 |

### 本地跑 Streamlit 版

```bash
pip install -r requirements.txt
streamlit run app.py
```

首次运行会通过东方财富行情接口抓取日线并重采样为月度数据，缓存到 `data/nasdaq100_monthly.csv`（该文件不入库，可随时重建）。

## 数据来源

QQQ（Invesco QQQ Trust）前复权日线，2001 年至 2026 年，经东方财富行情接口获取。ETF 的前复权价格已计入分红再投资，因此回测结果包含股息收益。
